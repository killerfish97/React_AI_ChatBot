# 🤖 AI Chatbot React App

An intelligent AI-powered chatbot built using React that provides real-time responses and a smooth conversational UI.

---

## 🚀 Features

* 💬 Real-time chat interface
* 🤖 AI-powered responses 
* ⚡ Fast and responsive UI
* 🎨 Clean and modern design
* 📱 Mobile-friendly

---

## 🛠️ Tech Stack

* Vite + React.js
* JavaScript (ES6+)
* CSS / Tailwind
* API Integration (OpenAI / backend)

---

## ⚙️ Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/your-username/ai-chatbot-react.git
```

2. Navigate to project folder

```bash
cd ai-chatbot-react
```

3. Install dependencies

```bash
npm install
```

4. Start the application

```bash
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file and add:

```
REACT_APP_API_KEY=your_api_key_here
```
